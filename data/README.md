# Data directory

`raw/` and `processed/` содержат только локально сгенерированные артефакты и не коммитятся в Git.

## `credit_applications.csv`

Одна строка — срез заявки на момент принятия решения. Целевая переменная — `default_90d`.

## `transactions.csv`

Одна строка — срез транзакции в момент авторизации. Целевая переменная — `is_fraud`.

Оба датасета генерируются командой из корневого README. Фиксированный `--seed` гарантирует, что коллега или ревьюер получит те же данные.
