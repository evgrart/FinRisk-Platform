# Development workflow

Проект развивается небольшими вертикальными этапами: каждый коммит должен добавлять законченный кусок поведения и проходить проверки.

## Локальная проверка

```powershell
python -m compileall -q src tests
pytest -q
```

## Формат коммитов

- `chore:` — структура проекта, конфигурация и инструменты;
- `feat:` — новая функциональность;
- `test:` — тесты без изменения поведения;
- `docs:` — документация.

Перед коммитом нужно проверить, что в Git не попали `.venv`, сгенерированные CSV и model artifacts.
